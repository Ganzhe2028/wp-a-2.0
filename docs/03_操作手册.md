## 1. 环境准备

### 生产地址

线上已部署：`https://msoweek.site`（Vercel，GitHub `main` 分支 push 自动部署）

### Node.js

需要 Node.js 18 或更新版本。从 [nodejs.org](https://nodejs.org) 下载 LTS 版安装。

验证：

```bash
node -v   # 应 ≥ v18
npm -v    # 应 ≥ v9
```

### 代码获取

```bash
git clone <仓库地址>
cd wp-a
npm install
```

如果 `npm install` 很慢（国内网络），先设淘宝镜像：

```bash
npm config set registry https://registry.npmmirror.com
```

### 数据库：Neon PostgreSQL

1. 注册 [neon.tech](https://neon.tech)（GitHub 登录最快）
2. 创建 project，region 选新加坡 `ap-southeast-1`
3. 拿到两个连接串：
   - **Pooled** 连接串 → `DATABASE_URL`（带 `-pooler` 的 host）
   - **Direct** 连接串 → `DIRECT_URL`

### 图片存储：Cloudflare R2

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 左侧 R2 → Create bucket，名称 `owek-images`，region 选 Asia Pacific
3. 进桶 Settings → Public Access → Enable，记下公开域名
4. Settings → CORS Policy → 添加：

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "PUT"],
    "AllowedHeaders": ["*"],
    "MaxAgeSeconds": 3600
  }
]
```

5. R2 首页右上角 Manage R2 API Tokens → Create Token → Object Read & Write → 记下 Account ID、Access Key ID、Secret Access Key

## 2. 配置

复制环境变量模板并填入实际值：

```bash
cp .env.example .env.local
```

必须填的变量：

| 变量 | 说明 | 从哪拿 |
|---|---|---|
| `DATABASE_URL` | Neon pooled 连接串 | Neon dashboard → Connection string → Pooled |
| `DIRECT_URL` | Neon direct 连接串 | Neon dashboard → Connection string → Direct |
| `R2_ACCOUNT_ID` | Cloudflare 账号 ID | R2 API Tokens 页面 → URL 里那串 |
| `R2_ACCESS_KEY_ID` | R2 API 密钥 ID | 创建 token 时显示 |
| `R2_SECRET_ACCESS_KEY` | R2 API 密钥 | 创建 token 时显示（只出现一次） |
| `R2_BUCKET` | 桶名 | 填 `owek-images` |
| `R2_PUBLIC_BASE_URL` | 公开域名 | 桶 Settings → Public Access → 域名 |
| `ADMIN_PASSWORD` | 后台口令 | 自己设 |
| `SESSION_SECRET` | 学生 session 签名密钥 | `openssl rand -base64 48` 生成，≥32 字节 |
| `APP_BASE_URL` | 应用根 URL | 本地 `http://localhost:3000`，生产填真实域名 |

`ADMIN_PASSWORD` 和 `SESSION_SECRET` 都是必填项。缺失或空字符串时，auth 相关接口会直接失败，不会使用默认密钥降级运行。

本地开发时，`/admin` 登录页会显示 `.env.local` 的 `NEXT_PUBLIC_LOCAL_ADMIN_PASSWORD`，方便运营测试。该变量仅限本地开发，**绝不能**配置到 Vercel 或任何生产环境。

---

`.env.local` 供 Next.js 本地开发读取。Prisma CLI 默认读取 `.env`，因此本项目执行迁移时必须显式设置 `DOTENV_CONFIG_PATH=.env.local`；仅启动 `npm run dev` 不需要额外设置。

## 5. API 速查

全部接口：

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| `POST` | `/api/auth/login` | 无 | `{ username, password }` → 返回 session cookie |
| `POST` | `/api/auth/logout` | cookie | 清 session cookie |
| `GET` | `/api/me` | session | 获取自己的数据 |
| `PATCH` | `/api/me` | session | 更新自己的数据（姓名 ≤ 40、年级 ≤ 20、bio ≤ 80、头像 URL 必须来自 R2 且 key 归属本人） |
| `POST` | `/api/upload-url` | session | `{ contentType, purpose? }` → presigned PUT URL + key；每人 10 分钟最多 20 次；提交后需 `allowEdit` 开启 |
| `POST` | `/api/me/images` | session | 保存图片记录（上限 14，Serializable 事务终检） |
| `DELETE` | `/api/me/images?id=` | session | 删除图片（R2 + DB） |
| `GET` | `/api/me/submissions` | session | 自己的 Day1/Day3 提交状态与草稿 |
| `PATCH` | `/api/me/submissions` | session | `{ action: submitDay1 \| saveDay3 \| submitDay3, answers? }`；重复提交 409 |
| `POST` | `/api/admin/login` | 口令 | `{ password }` → 返回 admin cookie；同 IP 15 分钟最多 10 次 |
| `GET` | `/api/admin/session` | admin cookie | `{ authed: true/false }` → 校验当前会话 |
| `POST` | `/api/admin/logout` | admin cookie | 清除 admin cookie 登出 |
| `POST` | `/api/admin/import` | admin cookie | `{ rows: [{ chineseName, englishName?, groupName?, role?, username? }] }` → 返回含明文密码 |
| `GET` | `/api/admin/export` | admin cookie | 导出 CSV（chineseName, englishName, username, code, homepage） |
| `GET` | `/api/admin/persons` | admin cookie | 后台人员列表 JSON（显式脱敏，不返回 passwordHash/editToken） |
| `PATCH` | `/api/admin/persons` | admin cookie | `{ id, chineseName?, role?, groupName? }` → 编辑账号 |
| `DELETE` | `/api/admin/persons?id=` | admin cookie | 永久删除账号 |
| `POST` | `/api/admin/reset-password` | admin cookie | `{ code }` → 返回新明文密码（只出现一次） |
| `GET` | `/api/admin/settings` | admin cookie | 所有系统设置键值对 |
| `PATCH` | `/api/admin/settings` | admin cookie | 更新单个系统设置 |
| `GET` | `/api/admin/qr/print` | admin cookie | 批量生成 QR 码打印页（每人一张 `/u` 码） |
| `GET` | `/api/settings?key=` | 无 | 公开读单个系统设置 |
| `PUT` | `/api/local-upload` | 本地开发 | 磁盘存储替代 R2（`LOCAL_UPLOAD_DIR` 开启时） |

## 6. 运营流程

### 导入学生

1. 打开 `/admin`，用口令登录
2. 切到「ACCOUNTS」→ 点右上角「同步 / 导入账号」
3. 粘贴数据，格式：`中文名,英文名,组别,角色,可选用户名`（每行一人；角色可填 `LEARNER`、`SENIOR` 或 `ADMIN`）
4. 点「确认导入」写库
5. 每人自动生成：code（短码）、username（默认同 code）、密码（12 位可打印字符，含大小写字母、数字和少量安全符号）
6. 导入是整批事务：任一行失败会整批回滚，不会产生半成功账号
7. **导入成功后立即抄录弹窗里的密码**——明文密码只在这一次出现
8. 把用户名和密码印在纸条上发给学生

导入接口使用批量事务写入：同一批名单要么全部成功，要么全部失败，不会留下半批学生。若名单里有重复用户名或数据库里已存在同名用户名，后台会显示具体错误；若看到 HTTP 500，需要先看后台页面上的错误文字，再查 Vercel function log。

### 重置并复制单个密码

在「ACCOUNTS」列表的「新密码」列点击重置按钮，或点开某行进入「编辑账号」抽屉点「重置密码」。确认后旧密码立即失效，系统会生成新密码并尝试复制到剪贴板。明文只保留在当前管理员页面；刷新页面后不能再次查看，需重新重置。

### 导出链接表

1. 「ACCOUNTS」→ 点「导出 CSV」
2. 拿到所有人的中文名、英文名、用户名、短码、主页链接（`/u/{code}`）
3. **密码不可导出**——存库的是 hash，导出 CSV 不含密码
4. 用链接写 NFC 标签、印二维码

### 隐藏某个人的页面

admin 界面暂无下架开关（2026-07-31 起）。需要隐藏时在数据库把该 Person 的 `hidden` 置为 `true`；前台 `/u/{code}` 会显示「该页面已隐藏」占位。

### 系统设置（活动开关）

「DASHBOARD」→「INDEPENDENT SWITCHES」，六个开关：

| 开关 | key | 关闭时 |
|---|---|---|
| Day 1 开放 | `day1Open` | 未提交用户不能进入 `/day1` |
| Day 3 开放 | `day3Open` | 未提交用户不能进入 `/day3` |
| 允许编辑 | `allowEdit` | 已提交作品只读；开启后可继续改图/改瓶子 |
| 显示姓名 | `showNames` | 全站姓名显示为匿名符号 ID |
| 显示完整资料 | `profileComplete` | `/u`、`/nfc` 只显示身份标题，不出图和瓶子 |
| 目录与跨页导航 | `navEnabled` | 隐藏 BROWSE 入口与 `/browse`；NFC 直达不受影响 |

上方「QUICK PRESETS」提供五个一键预设：DAY 1 创作 / DAY 3 创作 / 活动前浏览 / 游戏进行 / 找礼包（真实姓名 + 仅姓名 + 导航关）。

### 生成 QR 码

1. 「ACCOUNTS」→ 点「打印 QR」→ 新窗口打开打印页
2. 每人生成 1 张主页 QR（`/u/{code}`），A4 网格布局
3. 建议用 A4 纸打印后裁剪，贴到展板上

## 7. 账号管理（v2.0）

### 学生登录

学生在首页输入用户名和密码登录。用户名默认是短码（code）。登录后系统下发 session cookie（14 天有效），活动期间无需重复登录。登录后落在 `/home`，从三张卡片进入 DAY 1 / DAY 3 编辑器或 BROWSE。

### 忘记密码

学生没有自助重置入口。流程：组长联系开发 → 开发在 `/admin`「ACCOUNTS」找到该生 → 重置密码 → 系统返回新明文密码（只显示一次）。

### 登录态与浏览器

- Session cookie 是服务端 httpOnly 下发的，不受 iOS Safari ITP 影响
- **不能在微信内置浏览器里登录**——微信和 Safari 是独立 cookie jar
- 登录页会检测微信 UA，若在微信内打开，会提示「请在 Safari/系统默认浏览器中打开」
- 全程统一用系统默认浏览器
- 编辑过程中若 session 过期，页面会显示「登录状态已过期，请重新登录」卡片，点「重新登录」后会回跳到原页面

## 8. 常见问题

### 数据库迁移失败

先查看缺失迁移，再应用已提交的迁移：

```bash
DOTENV_CONFIG_PATH=.env.local npx prisma migrate status
DOTENV_CONFIG_PATH=.env.local npx prisma migrate deploy
```

不要用 `prisma db push` 强制覆盖已有数据库。若数据库已有表却缺少历史记录，先备份并比对 schema，再决定如何登记迁移。

### 学生无法登录

1. 确认 Vercel 环境变量里 `SESSION_SECRET` 已设置且够长（≥32 字节）
2. 确认账号已导入且明文密码已下载（存库的是 hash，无法还原）
3. 密码丢失直接用「重置密码」功能生成新密码

### 图片上传失败

1. 确认 `.env.local` 里 R2 五个变量都已填
2. 确认 CORS 策略已添加
3. 检查 R2 桶是否开启了 Public Access
4. 确认前端保存的是 `/api/upload-url` 返回的原始 `key`；不要从公开 URL 反推 key
5. 若学生同时上传多张图，最终 14 张上限由 `/api/me/images` 的事务校验决定，预签名接口只做前置拦截
6. `/api/upload-url` 有用户级内存限流（每人 10 分钟最多 20 次）。前端压缩不是安全边界，R2 端仍需靠限流和后续孤儿文件清理预案控制滥用。
7. 已提交 DAY 1 的学生默认只读；需要重新编辑时先在 admin 打开「允许编辑」（`allowEdit`）

### 构建报错

```bash
npx tsc --noEmit    # 先看类型错误
npm run build        # 再看构建错误
```

本地 `npm run build` 若报 `Missing required environment variable: DATABASE_URL`，是因为 `prisma.config.ts` 只读 `.env`。先 `set -a; source .env.local; set +a;` 再 build。

### 本地页面仍显示旧界面或报 hydration mismatch

`/admin` 当前界面为左侧黑色导航栏（`DASHBOARD`、`ACCOUNTS`、`AUDIT LOG`、`EVENT SETTINGS`）。若浏览器仍显示旧版标签页界面，说明本地 `localhost:3000` 不是由当前项目目录启动；停止该旧服务后，在本仓库运行 `npm run dev`。

浏览器翻译扩展（例如 Immersive Translate）会在 `<html>` 注入属性，可能触发 hydration 提示。页面已忽略该类根元素属性差异；若仍有提示，请在该站点暂时关闭对应扩展后刷新确认。

### Windows 下 Prisma 报错

如果 `prisma migrate dev` 报引擎下载失败，设环境变量后重试：

```powershell
$env:PRISMA_ENGINES_MIRROR="https://registry.npmmirror.com/-/binary/prisma/"
npx prisma migrate dev
```
