## 当前硬约束

1. 正式身份模型统一使用 `User` 与 `LEARNER | SENIOR | ADMIN` 三角色。本地账号是可长期独立运行的正式认证方式，学校 OIDC 是可选增强；共享 Admin 口令仍是待移除的旧实现。
2. 设置缺失或读取失败必须 fail closed，不得扩大写权限、浏览权限或公开范围。
3. 安全不能依赖前端隐藏；匿名响应在查询和序列化阶段不得包含姓名、姓名排序键、组别或可还原身份字段。
4. `/nfc/[code]` 与 `/package/[code]` 不得形成特殊权限入口；正式作品入口统一为 `/artworks/[publicId]`。
5. 正式领域模型目标为 Event、EventSettings、User、Group、Submission、Asset、Day1Slot、Day3Bottle、EventAnonymousId、ArtworkPublicId 和 AdminAuditLog；不得继续向原型 `Person` 堆字段。
6. Day 3 使用 `level: null | 0 | 1 | 2 | 3 | 4 | 5` 与 `isConfirmed` 区分未回答和主动选择 0；空内容不可提交。
7. 所有作品写入必须在事务中按最新正式设置重新授权；提交后的 Avatar、Slot 和 Asset 变更走同一 Submission 权限。
8. 普通账号使用 `ACTIVE | ARCHIVED` 软删除；最后一个 Admin 不得降级或归档。
9. 日志不得包含姓名、邮箱、Token、Cookie 或作品内容，只允许 requestId、稳定错误码和不可逆用户摘要。
10. Senior 默认只能浏览自己 Group 内的 Learner；未分组 Senior 必须 fail closed。Admin 始终可浏览全部，并可通过审计设置 `seniorCanBrowseAll` 显式放宽 Senior 范围；Gallery 和直接 Artwork URL 必须执行同一服务端权限。
11. Day 3 填写与作品展示必须保留两个主题的标题和说明；瓶子不能脱离主题上下文混排展示。
12. 学生弹窗必须相对浏览器视口定位，不能受长页面、滚动位置或进入动画的 containing block 影响。
13. Group 可由 Admin 创建、重命名和删除；删除 Group 只解除成员的 `groupId`，不得删除账号或作品。被解除分组的 Senior 继续按 fail-closed 规则处理。
14. NFC 写卡使用正式 `/artworks/{publicId}` 作品链接。Admin 可批量导出 ACTIVE 账号及其展览网址；不得启用 `/nfc/[code]` 作为特殊权限入口。

## 契约优先规则

- 正式 API 以 `/api/v1` 为建议 Base Path。
- 先修改 `lib/contracts/**`，记录兼容性影响，再实现 API，最后由 UI 接入。
- 数据库模型不得直接暴露为公共 API 类型。
- 当前实现已经在该信封、requestId 和稳定错误码之上完成正式业务 API、领域状态机与 OpenAPI 合同；后续修改仍必须先更新契约再改实现。

成功响应：

```json
{
  "data": {},
  "requestId": "req_..."
}
```

失败响应：

```json
{
  "error": {
    "code": "AUTHORING_CLOSED",
    "message": "当前处于只读阶段",
    "details": {}
  },
  "requestId": "req_..."
}
```

## 工程门禁

固定 Node.js 22.14.0 与 npm 10.9.2。干净 checkout 必须依次通过 `npm ci`、lint、typecheck、test、Prisma 生成产物可复现检查、build 和 harness。CI 不访问生产 Secret 或生产数据，数据库 URL 仅使用不可连接的本地占位值完成静态构建。

## Agent 所有权

- 后端与平台：`prisma/**`、`app/api/**`、`lib/auth.ts`、`lib/prisma.ts`、`lib/server/**`、`lib/domain/**`、`lib/contracts/**`、`lib/observability/**`、平台配置与后端测试。
- UI 与前端：学生端和 Admin 页面、组件、全局样式、视觉资源与 E2E。
- Migration 由后端 Agent 独占创建。跨边界需求先更新契约并记录 handoff，不直接修改另一方所有权文件。
